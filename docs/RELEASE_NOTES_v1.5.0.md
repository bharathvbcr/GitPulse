# GitPulse 1.5.0

GitPulse 1.5.0 is a large release: agents that run in the background with a pane of everyone at work, a much richer task board, pull-request review, repository-wide search, a ledger that now records Codex as well as Claude, and a lot of work on terminal reliability, idle cost and the trust boundary around hooks and notifications. It covers everything since v1.3.1, the last published release, because v1.3.5 and v1.4.0 were never published and their changes are included here. To upgrade, install the 1.5.0 build, then read Breaking changes below: the task profile is migrated one way, and `gitpulse-mcp` and `gitpulse-hook` need reinstalling.

## Highlights

- **Agents start in the background.** Launching an agent from a task no longer closes the task sheet. The task's Agents pane lists every attempt working on it, and board cards show how many agents work on them and how many need you. (`576e005c`, `389a3498`)
- **Several agents at once, each in its own worktree.** You choose how many agents run at once (Settings, Agents, default 8) and how many terminal sessions may be open (default 32, up to 128). An agent can mark its own task done when the work is finished. (`a16e9171`, `5e547be5`, `421b4404`, `acd6116c`)
- **Bypass permissions mode is reported, not enforced.** In a Claude Code session the person put in bypass permissions mode, `command-gate` and `collision-guard` still run every check (the MANVI harness, task scope, collision scan and signal guard) but say what they would have refused instead of enforcing it, as a notice to the person and context for the model, so the host's own bypass rules decide. Every other mode, an empty value and a missing one are gated exactly as before. (`839b2408`)
- **Stacked worktree tabs.** Every checkout of one repository shares one tab with a switcher, so agent worktrees stop pushing other repositories off the tab strip. (`88ae7ae9`, `d127042c`)
- **A model for each agent.** Settings, Agents, Agent models sets the default model per agent CLI, and a task handoff can pick a model, effort and advisor for a single launch. Every handoff now opens with the same agent guidance. (`16c79e71`, `35ea0410`, `c68e9b3a`)
- **Manvi can run on Claude, and its proposals and verdicts have a home.** A "Manvi's model" card points Manvi's own model at a Claude model with an API key held in the login Keychain (it never reaches the page). A Proposals panel reviews Manvi's scan and refine proposals, and a task's verdict can be posted to GitHub as a `devcouncil/verify` commit status, per repository and opt-in. (`bcc9611b`, `cf07ebc2`, `03ca87ad`)
- **A fuller task board.** Undo, swimlanes, saved views and work-in-progress limits, checklists and task links, restore from a Deleted view, a query language for search, and Suggest next. The board orders by priority by default, in columns and in the List layout. "Run in waves" launches the top suggested tasks in their own worktrees and merges only work with a passed verification, never pushing. (`389a3498`, `cb4ab882`, `3a7de123`, `f0c78a46`, `69d91131`, `d7545e04`, `8032c383`, `ed682267`)
- **Hide a repository's tasks.** A repository row in the Tasks sidebar can be hidden: its tasks leave the All and workspace boards, and its own board still shows everything. A task goes by the repository an agent runs in. See Known issues for what hiding does not yet reach. (`2b56f3bf`)
- **Agents can delete and merge board tasks, and must group findings.** `gitpulse_delete_task` and `gitpulse_merge_tasks` exist, and `gitpulse_add_task` refuses a new card that looks like open work until the agent has read the related cards. (`f9d4fc9d`, `0f0ffbda`, `607ad2da`)
- **Pull requests, search, files and history.** A pull request can be viewed, reviewed, merged and opened through `gh`. Code, Search searches file contents. The file tree renames, moves and deletes tracked files. From a reflog entry you can create a branch or reset the current branch, and Blame can show a file at a revision. (`ff0e7c40`, `bcf18867`, `d5f159df`, `3c27d41c`, `75e393ad`)
- **Two agents in one worktree are visible.** Collision risk flags dirty files in any worktree two live sessions share. Sessions are found by process scan on macOS and Linux, so running Codex sessions are counted there too. (`2c3d6707`, `f27fc1ae`)
- **Codex sessions are recorded in the ledger.** Transcript catch-up reads one source per agent, and Codex rollouts (`$CODEX_HOME/sessions`, default `~/.codex`) become `session.edit` and `session.command` rows with actor `codex`, read after the fact. Straight-line code-mode programs are parsed within fixed bounds; any call it cannot read is counted in `skipped_lines`, never guessed. (`83c1ea6c`, `f0ccddfa`, `2137fe7e`, `07940b6b`, `d87d7c66`)
- **Dead-branch cleanup and a Secrets scan.** Stale branches are scanned and cleaned with a restorable backup per repository. An optional secrets scan locates each finding and never calls a partial scan clean. (`9706f20d`, `a20f8d58`, `86fdf28c`)
- **Agents keep running when their view goes away, and terminals can outlive GitPulse.** A stalled, hidden or reloaded view no longer kills an agent. On macOS, Cmd-Q, Dock Quit and the Quit Apple event reach the quit confirmation, and a second launch hands over to the running GitPulse. Settings, Agents, "Keep terminals running when GitPulse quits" (off by default) holds terminals in a separate `gitpulse-ptyd` process that is adopted on the next launch. (`fe6236ef`, `8c9feada`, `998c43a2`, `b862aa28`, `9d693711`, `6ca14b3a`)
- **Git work is admitted by class.** Interactive, reactive and background git work are admitted separately, and all GitPulse processes share one per-user spawn budget, so a refresh storm can no longer starve an action you asked for. (`e9a64486`)
- **A host-load governor.** Under severe memory pressure GitPulse refuses agent launches with a clear reason and sheds its own background work. Your shell and stop, kill, cancel, save and commit are never gated. Health shows the state and offers **Admit anyway** (two minutes, after a native confirmation). Low free disk space is advice only. (`73163a50`, `e96541bb`, `6a8c14d8`, `b5c765be`)
- **Lighter at idle and with many tabs.** A repository is read one snapshot at a time, switching back to a freshly read tab costs no read, open tabs keep history for only the 6 most recent repositories, terminal scrollback is a setting, and idle watchers, the single-instance mailbox and idle terminals wait for events instead of polling. On macOS, background git children and pool threads run at background QoS. (`296eb20b`, `5b419492`, `7dc5c132`, `3d1c9bae`, `05e734a7`, `7c984121`, `bde04e9d`)
- **GPU terminal rendering, on by default.** Visible terminals draw through WebGL (at most 8 at once) and fall back to the DOM renderer after a lost context. Settings, Appearance, GPU terminal rendering turns it off. See Known issues. (`75bee0f9`)
- **Storage panel commit-graph write.** A user-clicked, gated `git commit-graph write --reachable --changed-paths` for repositories missing commit-graphs or Bloom filters, previewed, judged by the command gate and cancellable. (`d7aa79a2`, `e9e521f5`)
- **Ledger site binding and adoption.** A ledger is bound to its anchor directory, lineage UUID, inode and volume UUID. A ledger moved across sibling clones is refused; **Adopt this ledger** (`cmd_adopt_ledger`) allows a safe takeover with an audit row. (`2e904ff4`, `f053e297`)
- **Would it merge, and did it land.** `gitpulse_merge_conflicts` checks whether pairs of checkout heads would merge cleanly over an isolated object quarantine, and `gitpulse_landed` proves whether a commit's work reached a base branch (`merge`, `ff`, `squash`, `rebase` or `tree`) and says null, with a reason, when absence is not provable. Insights worktree rows show `head`, `ahead`, `behind` and `commits_since_base`. (`d3d947f8`, `14aced7e`, `a678ed7c`, `c22e9073`)
- **Banners can be offered to Graft.** A delivered banner is also enqueued for Graft's local socket, best effort inside a hard 1 s budget on its own thread, so an absent or hung Graft never delays a banner. (`495b18c9`)

## Fixes

- **A slow host no longer kills terminal input.** Input waits for the real answer, shows one "responding slowly" notice, and stops only when the session is gone or nothing answers for 60 seconds. (`2e313355`)
- **Typing and resizing no longer queue behind git.** Terminal commands run on their own bounded executor instead of the pool git shares. (`e2c11933`)
- **Terminal output travels on a per-session channel** of raw bytes, up to 64 KiB a message, instead of a global event sent to every webview. (`3b1cf774`)
- **A Claude tab ended by a signal offers Resume** for the same conversation, directory and mode. (`6fc50cb2`)
- **Branch names git allows now work,** such as `fix/a&b`, `feat(ui)=x` and `a]b`. A leading `-` and control characters are still refused. (`de7b53f2`, `2dba1c9e`)
- **A commit that finishes after you switch repository tabs** no longer clears the other repository's message or amend flag. (`05e734a7`)
- **Send to agent from a board card no longer crashes,** and the branch menu's Push, Pull and Checkout work again. (`dc045c1f`)
- **Remote branch rows check out as a local branch** and no longer detach HEAD. (`d7ca958e`, `ff3c9628`)
- **Open tabs and groups survive quitting, and repository trust survives reboots** and toolchain updates. (`c6214518`, `a3323787`)
- **More than 24 repositories can be open,** and agents in worktrees no longer need a repository tab of their own. (`fe4393d3`, `edb364c1`)
- **Closing a working agent asks first,** and names its task. (`e27e6daf`)
- **Removing or merging a worktree refuses while any process is working in it.** (`438a21e2`)
- **The file editor no longer rewrites non-UTF-8 or mixed line-ending files.** Saves are compare-and-save with a conflict banner, and New File and New Folder create only. (`a4149eb1`, `30e30fdb`, `4c34c5c4`)
- **A partial scan is not reported as complete.** Dependency and coverage scans return by one 90-second deadline and a cut coverage report is marked truncated. A secrets scan that could not read a file is not "clean". (`1b91f9a6`, `86fdf28c`)
- **Size walks count what they could not read.** Storage and Insights walks count unreadable and non-UTF-8 entries, a permission refusal or missing root makes a total a floor, and unread worktree admin is never offered as reclaimable. (`1ddae839`, `14079d55`, `2a9758fa`)
- **One failing GitHub alert tier no longer hides the others.** The failing tier is named and Health shows the result as incomplete. (`3cafbd11`)
- **A wide Markdown table keeps its words whole and scrolls** instead of squeezing every column to a character. (`cc07dc52`)
- **A file-system event with an odd path or a panic in the handler no longer aborts GitPulse on macOS.** (`4d4c04d2`)
- **The update check announces published releases, not tags,** and a check that cannot be made fails rather than guessing. (`cf0fe90f`)
- **An update check that could not reach GitHub no longer reports "up to date".** A failed lookup, timeout, refusal or server error used to read as "not published"; now only a "not found" does, and anything else fails the check with its reason. (`d414ad3f`)
- **Closing a tab group releases its tabs** the way closing a single tab does. (`8b47801d`)
- **A moved or renamed repository takes its ledger over** instead of refusing to record. (`fbe3e99b`)
- **Reflog replay resumes from watermarks** per worktree and ref, covering the full worktree family and default branch in one transaction. (`79bccca6`)
- **Transcript cursors carry fingerprints** (head, tail, length, mtime), so rewritten transcripts re-read and moved files resume cleanly. (`a8990f56`)
- **A transcript row is recorded once however often its line is read.** Rows get a deterministic id from their identity, so a stale cursor, a forget or a second root spelling cannot duplicate them, and a transcript root confirmed absent for five passes is retired so forgetting resumes. (`5f74307b`, `7a1fac03`, `a4988026`, `0f147975`)
- **Ledger answers over MCP say how current and how whole they are.** `as_of`, `last_catch_up`, `stale` with a reason, `recording_state` (a read-only open is `readable`, never recording), `dropped_scope` and the legacy-ledger caveat are added to the ledger tool, resource, status and insights facet. Fields are only added. (`3cf5283e`, `8bf9be05`, `d512f8ef`, `8b19f8e8`)
- **The transcript walk counts what it leaves out.** It reads the workflow sub-agent layout, guards symlink loops by device and inode, and reports `transcripts_listed`, `transcripts_unlisted` and `walk_complete`; a tree past the depth or 5000-file cap marks the pass truncated instead of complete. (`3cf5283e`, `fa9d72cd`)
- **Ledger rows record when things happened,** not when a catch-up pass saw them, and the journal shows event time. (`8221b353`, `c71e8daf`)
- **Provenance and ledger queries answer what was asked.** `gitpulse_provenance` says where a commit sits relative to its base and reports `confidence` null for an unverified commit, and `gitpulse_ledger_events` can be read newest first and filtered by time, action, task, session, worktree and object. (`cfc873a5`, `bf08d80b`, `e284ae49`)
- **File & folder creation respects process umask** (`0o666 & !umask` for files, `0o777 & !umask` for executables and folders) instead of forcing owner-only permissions. (`e6578626`)
- **The pre-edit collision check asks about the file,** not the repository-wide overlap list. It reads one path-limited status per worktree, fails closed on a binary diff, matches case-insensitive volumes and nested repositories, and ask-gates an edit it cannot locate. (`ef14faab`, `fab6081f`, `95a1f515`)
- **The in-flight edit collision hook asks the running app** for its cached collision scan, cutting spawned git processes during edit bursts (40 to 8 git children over 7 worktrees), and a fresh hook process reuses the authenticated worktree family instead of asking git again. (`97b80ff3`, `f62defe6`, `68583830`, `5866c834`)
- **The hook bridge survives accept errors.** Transient errors (EMFILE and the like) back off and keep the socket, each connection is read on its own supervised worker (at most 100 open, a 1.2 s ceiling under the hook's budget), and reports are ordered by accept stamp. (`877828c9`, `ec7db790`)
- **An agent's MCP read waits for the shared spawn budget** instead of being refused at 0 s, a load-shed worktree resolution answers `deferred_worktree` with `retry_after_ms` and is retried once, and a refusal names its bucket and level. (`58040b6c`, `16028713`, `14c2bfb0`, `88913048`, `7c938836`)
- **A hook-running git command retries only on git's own `index.lock` failure,** never on a hook's or a network command's output. (`9a11a7f3`, `39c05a8d`, `56b3ddc9`)
- **Command errors carry a type from the code that raised them.** The retry, stash refresh, identity and trust prompts read the error's `kind` instead of matching message text, and only reviewed reads are retried. (`56335739`, `5a2e0d21`, `842c7b48`, `517615ec`)
- **A busy database no longer fails or restarts the ledger and churn cache.** One owner switches them to WAL with a bounded wait, and the churn schema rebuilds in a single transaction. (`1900229e`, `b947654e`)
- **A sidecar farewell larger than its output queue no longer gets the child killed** in its own shutdown grace. (`258cc575`, `130368aa`, `4e5dee9e`)
- **Resolving a worktree no longer leaks a file descriptor each time,** which a burst of 100 terminal sessions turned into hundreds. (`45ec47b6`, `62f1957a`)
- **Non-ASCII names no longer panic** the remote URL parser, the `tasks/` scan or the commit-graph HEAD reader. (`ff32f57c`, `c12c6108`)
- **Pulse's ownership report samples the highest-churn files of every area** and blames them under git's own mailmap rule. (`ba52e1f1`, `b5397d40`)

## Hardening

- **The app enforces an ACL on its own commands.** The main window gets only the commands the frontend calls, the status popover only its three, and webviews cannot navigate off the app origin. (`08607bfd`)
- **Trust and tool changes ask in a native dialog the page cannot answer.** Trusting a repository, and repointing devmap or manvi at a new binary or source root, need a native confirmation. Open-in-default-app requires a trusted repository and confirms executables. (`87d03fc8`)
- **Remote images in repository Markdown stay withheld until you click them,** and load over https only. (`08607bfd`, `a047354d`)
- **A withheld picture loads only from text that parses as an https URL,** and the parsed URL, not the attribute's text, is what reaches `src`. (`c87a0ed8`)
- **Remote tool installs are pinned.** They build one exact commit from a fixed directory, curl is confined to https, and clone refuses Git older than 2.45.1 (submodule recursion older than 2.50.1). (`3f09e029`)
- **Every signal GitPulse sends goes through one guarded primitive** that refuses pid 0, 1 and negative ids, its own process, and a pid whose start time moved. (`0709eded`)
- **Agents' kill commands are checked.** The command gate refuses a `pkill`, `killall` or similar that would reach agent sessions, GitPulse or more than 25 processes. (`8c03e89e`)
- **An out-of-repo operand is left to the host's rules, in an unbound checkout only.** A command whose only refusal is `command.operand.unverifiable` (a program the harness does not model handed a path outside the repository, such as `jq . ../x/package.json`) is reported instead of refused, like `cd` and heredocs. It needs a `manvi` that marks the refusal `policy.unreadable_only`, and a worktree bound to a task keeps the hard refusal. (`901c715b`)
- **Hook reports must name a session the terminal registry knows,** and each session is rate-limited. A report for an unknown session is refused as `unknown_session` and a flood as `rate_limited`. (`cb453930`, `8d921144`)
- **The hook-report protocol says what it did.** The socket acks only what the worker took, every refusal carries a reason from a closed set (with `max_v` for version refusals), a tombstone covers each ended session, the queue is capped per class, and a clip is measured on the serialized size. (`49e59a05`, `add94a0a`)
- **Notify text has one cleaner and one hidden-character table.** Every display channel goes through `alerts::text`, Rust and TypeScript share one generated table of hidden code points, route guards catch a retargeted notify entry, and the plugin's SessionEnd hook timeout drops from 5 s to 1 s so it cannot raise Claude Code's exit budget. (`5b3c82b9`, `fbdc7105`, `26d2444e`)
- **Notify events ride into every GitPulse-launched Claude.** PermissionRequest, PostToolUse, UserPromptSubmit, Stop and SessionEnd are injected beside PreToolUse (report-only), a twin report from plugin and injection folds into one, and `notify` reads no stdin when it has nothing to report. (`4c1d00b5`, `46b40ea7`, `311918de`)
- **Outbound data goes only where you chose.** npm and bun scanners run with an allowlisted environment and a pinned npm config, and a repository-set registry, token, proxy or TLS setting refuses the scan. With no chosen AI endpoint, a discovered local server is offered for confirmation and nothing is sent until you confirm and the choice persists. (`9be2dbf8`, `6a38d40a`, `1f55854f`, `7036aa93`)
- **A sibling worktree can no longer author a binding the gate honours.** The newest binding is the highest row id, not the latest clock stamp, and binds imported from a sibling after the anchor are history only. This narrows authority and widens none. (`0b523ef2`, `098edb06`)
- **The file sandbox also refuses nested git directories and spelling tricks.** Delete or move of a folder holding a nested gitdir, HFS and backslash `.git` spellings, and a symlinked `.gitmodules` are refused, and a symlink to a gitdir is the entry rather than a gitdir. (`3eabc664`, `1f307442`, `18e4787d`)
- **Remote credentials stay out of the webview.** Remotes list display URLs plus `has_credentials`, the judge, verdict and ledger see only display URLs, and fetch, pull and push refuse a name that is not a configured remote. (`6cd82e61`, `c955bc3f`)
- **Manifest and lockfile reads are bounded and no-follow,** and the XML entity decoder is linear. (`e8b22d5d`, `292b849c`)
- **Ledger event strings are bounded,** and every cut is recorded in a sibling field, never in an array or `detail_json`. (`d56469de`, `667dd8b0`)
- **Manvi's Claude key is gated on Manvi's promise.** It travels on stdin, never argv; it is read only after `manvi version --json` promises to withhold `ANTHROPIC_API_KEY` from every child, and the handshake checks it again; a Claude selection may not name a base URL. (`bcc9611b`)
- **Previews and saves refuse oversized content at the command boundary,** before any copy is made. (`2105086c`)
- **Copying build caches into a worktree is all or nothing,** and only into a worktree of the same repository. (`80bd78c4`)
- **A peer that drips bytes cannot hold the alert bridge or the code-index probe open.** One wall-clock deadline covers both. (`c4155156`)
- **The shared spawn budget no longer resets to a full burst when its record is unreadable.** (`6ab65c15`)
- **Merging an agent attempt nobody reviewed is refused,** behind a per-repository opt-in. (`03b6b700`)
- **The file sandbox refuses reads and writes of `.git` metadata** from the webview. (`30e30fdb`)
- **A build that would ship source maps fails,** and the release job no longer runs install scripts with the GitHub token or persists checkout credentials. (`b9b9e116`, `4a8b4eb0`)
- **The shipping and ARM bundle builds pass `--locked` to cargo,** so installers are built from exactly the committed `Cargo.lock`. (`83923d3c`)
- **Every workflow pins its actions to commits.** No checkout keeps its token, Bun's version comes from `package.json`, and `check:workflows` refuses an unpinned action or a credential-keeping checkout. (`1603c69d`)

## Breaking changes

- **The task profile is migrated one way, to dc-store store schema 11 and workbench schema 14.** A host built against an older schema refuses a migrated profile. Rebuild GitPulse, Manvi and DevCouncil from the same dc-store before any of them opens the profile. (`3a7de123`, `c6b92930`, `6c0e1faa`, `0fdab295`, `ad799955`)
- **The minimum supported Git is now 2.36, up from 2.23.** Worktree listing uses `git worktree list -z` with no fallback; the version check names every feature an older Git lacks. Force push now sends `--force-with-lease --force-if-includes` so a background fetch cannot defeat the lease. (`fec0b896`, `258cc575`, `28ee55a2`)
- **The ledger schema bumps to writer generation 2 (OD 1).** Additive columns and tables for occurred time, reflog ordinals, and deduplication indexes. Older generation 1 binaries (`gitpulsed`, `gitpulse-mcp`) refuse to write a migrated ledger and must be rebuilt and reinstalled together. (`f053e297`)
- **Dead `cmd_stash_pop` IPC command removed.** `GitWriter::stash_pop` and `cmd_stash_pop` are removed in favor of `cmd_stash_action` with target OID. Registry stands at 291 handlers. (`6869235a`, `72dea9cc`)
- **Reinstall `gitpulse-mcp` and `gitpulse-hook`** (`bun run mcp:install`). An older binary carries an older `devmap-store` and cannot read a store a current `devmap` has built. `bun run check:schema-parity` asks every installed reader which schemas it reads, including the devmap extraction schema (97). (`710aa9e0`, `650a587a`, `2cf45493`, `205a72ef`)
- **Child processes drop relative `PATH` entries** (`.`, `bin`, `./node_modules/.bin`). A setup that relied on one must use an absolute path. The Manvi sidecar starts from an allowlisted environment, so provider keys and tokens set in the launching shell no longer reach it. (`87d03fc8`)
- **An agent can no longer mark a task done on its own word.** `gitpulse_complete_task(done)` leaves the task in review unless Manvi recorded a passed verification for the worktree's current head. A person moving a card is unaffected. (`50eedd43`)
- **`gitpulse_add_task` refuses a new task that looks like open work.** An agent must fold into a listed card, or call again naming every listed `item_id` in `reviewed_related`. (`607ad2da`)
- **Repository hooks (`.gitpulse/hooks.json` and `hooks.toml`) no longer run until you approve the file.** Any edit asks again. (`782cd07d`)
- **Hook reports from a session the terminal registry does not know are refused.** A Claude session outside a GitPulse terminal no longer raises banners or attention through the hook bridge. (`cb453930`, `8d921144`)
- **Clone refuses Git older than 2.45.1,** and submodule recursion refuses Git older than 2.50.1. (`3f09e029`)
- **A released app whose `gitpulse-hook` cannot be found now blocks agent calls** instead of letting them through. Make sure the hook resolves beside the app. (`32fe572c`)
- **On macOS, Option is Meta in the terminal by default.** A layout that types a character with Option (such as `@` on a German keyboard) must turn off Settings, Appearance, Option as Meta in terminals. (`d6c5a40d`)

## Known issues

- **The GPU terminal renderer shipped before its deciding benchmark ran.** It is on by default. The TUI-redraw A/B in `docs/PERFORMANCE.md` has not been run. A lost context falls back to the DOM renderer, and the setting turns it off. (`75bee0f9`)
- **A `gitpulse-mcp` or `gitpulse-hook` older than this build refuses a task store this build has opened.** Reinstall them together with the app (see Breaking changes). (`ad799955`)
- **Hiding a repository's tasks is a reader preference with gaps.** Store totals and per-column paging do not account for hidden tasks, and the archive, inbox, badges and suggestions still include them. Closing these, and a real remove, needs a DevCouncil workbench schema bump. (`2b56f3bf`)
- **Prebuilt remote installs are unavailable.** None are pinned yet, so that install option reports itself unavailable and installs build from source. (`3f09e029`)
- **Collision risk cannot see running Codex sessions where there is no process scan.** On Windows a kind with no detector is reported as unknown rather than zero; macOS and Linux count Codex by process. Codex history reaches the ledger only afterwards, from its rollout files. (`f27fc1ae`, `83c1ea6c`)
- **Ledger limits.** A ledger on a platform with no inode stays on the roots-only rule, and a new checkout that reuses a deleted checkout's inode at the same path is indistinguishable from the original. An identical reflog entry whose older twin lies outside the 200-entry read takes the twin's ordinal, and transcript rows written before deterministic ids can be recorded once more after a reset. (`2e904ff4`, `79bccca6`, `7a1fac03`)
- **The macOS build is ad-hoc signed and not notarized, and Windows builds are unsigned.** Gatekeeper and SmartScreen warn on first launch. (`src-tauri/tauri.conf.json` `signingIdentity: "-"`; no signing secrets in `release.yml`.)
- **An installed 1.3.1 may announce 1.5.0 before its installers exist.** Builds older than the published-release check announce the newest tag as soon as it is pushed, so for the minutes before the draft is published that link leads nowhere. 1.5.0 itself waits for the published checksum file. (`cf0fe90f`)
- **v1.4.0 and v1.3.5 were never published.** Their changes are included in this release. v1.3.5 was withdrawn, and 1.4.0 remains the previous changelog section. People upgrading from v1.3.1 receive everything since v1.3.1. (`00ec2567`)
