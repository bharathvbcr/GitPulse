# GitPulse 2.0 (1.99.0 Beta)

GitPulse 2.0 is a major release of the desktop workspace, agentic control plane, and terminal host. It ships in the repository and bundle manifests as `1.99.0` (the 2.0 beta) so plain numeric release and macOS bundle versions sort before `2.0.0`. It is the first release published since `v1.3.1`, incorporating all changes from the unpublished `v1.3.5`, `v1.4.0`, and `v1.5.0` cycles alongside the 2.0 overhaul.

To upgrade from `v1.3.1`, install this build and read **Breaking changes & upgrade** below: the task profile moves one way (workbench schema 17, with Inbox merged into Backlog), the DevMap store moves one way to schema 29, the ledger bumps to writer generation 2, the terminal host (`gitpulse-ptyd`, protocol 3) is unconditional on Unix, and `gitpulse-mcp` and `gitpulse-hook` need reinstalling.

## Highlights

### UI Overhaul, Appearance & Workspace Navigation
- **Streamlined 4-view, 11-section layout and floating panes.**
  - **Work (`Overview · Remote · Tasks`)**: Resolve and Policy fold into the surfaces they act on. The 3-way conflict editor leads **Overview** whenever a merge, rebase, cherry-pick, or revert is parked; *Branch and tag cleanup* and *Policy activity* live as disclosures on Overview; and *Outgoing commits*, *Issues to Tasks*, and *Push release tag…* live on **Remote**.
  - **Code (`Explorer · Map`)**: Search and Blame are inline toggles inside Explorer, while **Map** opens on an overview of repository size, caps, and critical files with live build progress (`[n/5]`) and hover tooltips across files, symbols, and subsystems.
  - **History (`Graph · Diff`)**: Reflog (*HEAD moves*) and regression *Suspects* fold into Graph's `Commits | HEAD moves | Suspects` switcher above one shared commit-details pane (`reset --keep` and branch creation). **Diff** gains a **History (`⌥H`)** rail tab drawing the solved commit graph beside the diff, with rich commit hover cards (full body, `git notes`, recorded verification) and `Shift+click` `older..newer` commit-to-commit comparisons.
  - **Insights (`Pulse · Coverage · Health · Storage`)**: Secrets folds into **Health** under a single health verdict, and long report lists across Health, Storage, Hygiene, Pulse, Fleet, Coverage, and Map open on their first five rows with a **Show all N** control.
  - **Floating cards, avatars & roomier Settings**: Sidebars and workspace panes float as rounded cards on the window ground, graph rows render GitHub author avatars with initials fallback, Settings expands to `1024×736` (`208px` category rail) with grouped `gp-card` sections, repository tab context menus are streamlined with icons, Theme/Pulse SVG exports use the native save panel, and double-clicking a page header or empty background minimizes an expanded terminal dock.
- **Theme preset gallery, My themes shelf & macOS window wallpapers.**
  - **17 built-in theme presets (`src/lib/ui/appearance/presets.ts`)**: Standard (*Neural HUD*, *Reactor*, *Pure Black*, *Crimson*, *Phosphor*, *Synthwave*, *Paper*), Developer (*Amber CRT*, *Blueprint*, *Midnight IDE*, *Arctic*, *Solar Dark*, *Daylight*), and Science Fiction (*Nebula*, *Orbital*, *Neon City*, *Hyperspace*), each validated against the contrast guard and palette-derived material floor.
  - **My themes shelf (`savedThemes.ts`)**: Save the active look or retain up to 24 imported `gitpulse-theme/1` files across appearance resets.
  - **Window wallpapers (`backdrops.ts`, `wallpaperStore.ts`, macOS)**: Eleven seeded static SVG backdrops (*Mesh*, *Aurora*, *Topography*, *Prism*, *Dusk*, *CRT scanlines*, *Blueprint*, *Nebula*, *Orbit*, *Skyline*, *Warp*) or a custom raster image re-encoded to a `<= 2560px` JPEG in IndexedDB, painted beneath `--mac-shell-veil` and cleared under Reduce Transparency or increased contrast.
- **Stacked worktree tabs & collapsible repository groups.** Checkouts of one repository share a stacked tab with a checkout switcher, and inactive repository groups (and inactive tabs within groups) can collapse in the tab bar, via Settings → Layout, or through the Command Palette.

### Terminal Host, Manvi Hosting & Session Recovery
- **Unconditional Unix terminal host (`gitpulse-ptyd`, protocol 3) & default-on hosted Manvi.**
  - On Unix (`#[cfg(unix)]`), PTY sessions always live in `gitpulse-ptyd` ([Terminal host](TERMINAL_HOST.md)), surviving app quit or crash and saving scrollback transcripts to disk for takeover (`512 KiB` output buffer). Quitting asks whether to leave or stop active sessions.
  - **Settings → Agents → Keep managed agent runs running when GitPulse quits** (`keep_terminals_running`) defaults to on, hosting managed Codex and Claude runs in a detached `manvi serve --listen` process.
  - **Durable terminal session ledger (`terminal-sessions.v1.jsonl`)**: Bounded 64-row JSONL recovery log and `TerminalResume` (`--fork` support) across restarts and unexpected exits.
- **GPU terminal rendering (`@xterm/addon-webgl`), DEC 2026 sync & Unicode 11.** Visible terminals draw through WebGL (holding up to 8 contexts, keeping hidden contexts for 5 minutes to eliminate tab-switch lag, with 3-strike DOM fallback), delimit writes around DEC 2026 synchronized-output frames, load `@xterm/addon-unicode11` for wide emoji alignment, and expose **Count a terminal bell as waiting for you** (default off) in Settings → Agents.
- **Low-idle kernel waits & dedicated terminal executor.** PTY readers sleep in kernel waits (`kqueue` on macOS, `epoll`/`pidfd` on Linux) rather than 10 Hz `waitpid` polling, typing and resizing run on a dedicated per-session thread rather than behind Git commands, output travels on raw-byte per-session `Channel`s (up to 64 KiB), and **Send to agent** wakes live Claude sessions via an `asyncRewake` `deliver` hook or continues managed Manvi runs.

### Pre-Operation Undo, Turn Checkpoints & Codex/MCP Control Plane
- **Pre-operation Git snapshots (`refs/gitpulse/ops/<n>`) & agent turn checkpoints (`refs/gitpulse/turns/`).**
  - Allowed agent Git mutations record pre-operation snapshots via the desktop single-instance mailbox (`src-tauri/src/engine/git_writer.rs`), with CAS-verified restore (`cmd_undo_op_snapshot`) and dirty-worktree confirmation in Reflog.
  - When `turn_checkpoints.enabled` is set, hooks capture working-tree state at turn start and end via a private index preserving real index `mtime` and omitting `.env*` untracked files; agents inspect checkpoints and bounded patches via `gitpulse_turn_checkpoints`.
- **Zero-copy agentic worktrees, `.worktreeinclude` & instant DevMap seeding.**
  - Eleven `gitpulse_worktree_*` MCP tools (`create`, `switch`, `isolate`, `prune`, `merge`, `claim`, `release`, `send_message`, `overlay_sync`, `inbox`, `radar`) plus the `gitpulse-worktree` CLI and `gitpulse-rustc` CoW build-cache wrapper give parallel agents isolated checkouts and coordination over `<git-common-dir>/gitpulse/lanes/`.
  - Claude Code's `WorktreeCreate` and `WorktreeRemove` hooks (`claude --worktree`, `EnterWorktree`, isolated subagents) use GitPulse's CoW caches, approved `post_create` hooks, `.worktreeinclude` file copying, and a copy-on-write clone of the anchor's DevMap store (`seedDevmap`, query-ready in `~1.2 s` vs `~7.6 s` cold).
- **Live agent sessions (`gitpulse_sessions`, `agents.live`), per-run timelines & thread trees.**
  - `gitpulse_sessions` discovers running sessions (`is_caller`, `run_id`, `task_id`, `state`, `state_source`, `state_age_s`) with zero `git` spawns, and `gitpulse_insights` reports `agents.live` across Claude Code, Codex, Antigravity, DevCouncil, and Manvi plus `served_by` shared app-read metadata. Agents appear in per-run activity timelines (`session.state`) and a parent/child thread tree.
- **Codex ledger ingestion, commit provenance, landing checks & merge-conflict quarantine.**
  - Transcript catch-up ingests Codex rollouts (`$CODEX_HOME/sessions/**/rollout-*.jsonl`, including bounded `tree-sitter-javascript` code-mode calls) alongside Claude Code transcripts.
  - `gitpulse_merge_conflicts` checks pairwise worktree mergeability in a temporary object quarantine (`merge_tree_candidate`), `gitpulse_landed` proves how a commit reached a base branch (`merge`, `ff`, `squash`, `rebase`, `tree`), and `gitpulse_provenance` reports `verified` status and base distance (`landed_on_base`, `ahead`, `behind`). Ledgers bind to their checkout inode and volume UUID (`cmd_adopt_ledger` for deliberate takeover).

### Task Board (Schema 17), Agent Handoffs & Diagnostics
- **Workbench schema 17, five-column Tasks board & automatic fill.**
  - **Inbox merged into Backlog** (schema 16): five columns (*Backlog*, *Ready*, *In progress*, *Review*, *Done*), with `status:inbox` searches, saved views, and `tasks/` briefs automatically mapped to `backlog`. Schema 17 (`dc-store` at `b5215026`) adds cross-repo queues, a two-way GitHub issue sync outbox, and DAG launch readiness.
  - **Automatic column fill & `liveOnScreen` refresh**: After reading the initial 30 cards per column, `fillBoard` pages remaining cards in 200-card chunks up to 2,000 cards while the column cursor matches, and live task surfaces stay active whenever the window is on screen (even unfocused).
  - **Two-row header, Inbox dismiss/restore & MCP safeguards**: Two-row Tasks header, **Dismiss**/**Restore** on attention inbox notices, **Merge…** card folding on the board, `expected_revision` CAS protection on `gitpulse_add_task`, `reviewed_related` duplicate gating, `verdict_memo` caching, subtask parent progress, due-date/status filters, hidden-repository notices naming the repo, multi-agent concurrency limits (1–64 runs; 32–128 terminals), and CI watching on agent branches.
- **Manvi Anthropic account registry, Claude per-launch models & Firebase diagnostics.**
  - When `~/.anthropic-accounts` exists, GitPulse launches `manvi serve` via `anthropic-account exec --no-fallback --repo $HOME -- manvi` without reading or storing an Anthropic API key in GitPulse, showing `Cloud · <model>` on the status-bar pill (`HarnessBadge.svelte`).
  - Settings → Agents configures default models per agent CLI, task handoffs choose model/effort/advisor per launch, and the **Proposals** panel surfaces Manvi scan/refine proposals and opt-in `devcouncil/verify` GitHub commit statuses.
  - The Firebase App Hosting panel classifies CLI failures with redacted *Copy diagnostics*, isolates `firebase-debug.log` in temporary storage, and leaves timed-out rollouts as unknown outcomes so users never double-deploy.
- **Pull requests, search, reflog recovery, dead-branch cleanup, secrets scan & host-load governor.**
  - View, review, approve, and merge PRs via `gh`; search file contents repository-wide (`git grep`); scan and clean stale branches with durable tip backups; run a Kingfisher secrets scan; trigger Storage `git commit-graph write --reachable --changed-paths`; and govern agent launches under severe host memory pressure (`sysload::governor`, with human **Admit anyway**) plus class-tiered Git spawn budgets (`spawn-budget.v2`) and single-snapshot tab caching. Banners are also offered best-effort to Graft's local socket.

## Fixes & Hardening

- **Task-scope fences, path folding & hook protocol hardening:** `command-gate` fences argument-writing commands (`sed -i`, `tee`, `cp`, `mv`, `rm`, `truncate`, `touch`, `dd of=`, `perl -i`, `install`, `ln`, `rsync`, `patch`) and refuses `scope.other_checkout`; collision checks fold file-vs-directory, case-insensitive volume, and submodule paths (`ft-9cfd5574`), ask the running app first (`session-brief`, `collision-guard`), wait for the shared spawn budget (`deferred_worktree`), and log timed notification misses to `<socket>.drops`.
- **Antigravity (`agy`) hook compatibility:** Stopped registering `PreToolUse` hooks (`collision-guard`, `command-gate`) for Antigravity (`plugins/gitpulse/hooks.json`, `plugins/gitpulse-agy/hooks.json`) because Antigravity IDE 2.32.1 denied tool calls when a hook returned `{}` without `"decision":"allow"`. Informational notices without a permission decision now render as `{"reason": ...}` rather than `{"decision": "ask"}`.
- **Bypass mode & out-of-repo operands (Claude Code):** `bypassPermissions` sessions report what gates would have blocked without overriding the host, and `command.operand.unverifiable` is left to the host in unbound checkouts when `manvi` marks `policy.unreadable_only`.
- **Expanded secret redaction & supply-chain security:** Vendored `dc-redact` at DevCouncil `cbd51369` redacts Google OAuth (`ya29.`, `1//`, `GOCSPX-`), 25-char GitLab (`gldt-`/`glft-`/`glrt-`/`glwt-`), Slack `xoxe-`, AWS `ABIA`/`ACCA`/`A3T`, HuggingFace `api_org_`, and `curl` CLI passwords while dropping false positives; `zstd 0.14.3` and `pulldown-cmark 0.13.5` address RUSTSEC advisories; npm/bun scanners run under allowlisted environments; remote Markdown images stay withheld until clicked (`https:` parsed URL only); and signal guards (`procguard::signal`) enforce Linux `pkill`/`pgrep`/`killall`/`pidof` permission rules.
- **Process isolation, ACLs & file safety:** Strict command ACLs per window (main vs status popover), native dialogs for repository trust/tool repointing, gitdir spelling/symlink traversal blocks, non-blocking `git` credential separation from the webview, compare-and-save file editing without rewriting non-UTF-8/line-ending files, process-umask-respecting file/folder creation, and non-panic FSEvents/UTF-8 handling.
- **Health, Coverage, Pulse, Graph, Diff & Ledger fixes:** Health automatic scans wait for settle, skip fresh results, and report signal-killed secret scanners cleanly; bare `git push` planning reads branch upstream config without falling back to `-u` on error; dependency/coverage scans enforce a 90 s budget and mark cut scans incomplete; failed reads never display as empty; Pulse DORA/velocity/ownership handle empty priors, `.mailmap`, and area sampling; Diff/History keep selections pinned across reloads, separate range diffs from working-tree files, and allow Go-to-line; read-only hook ledger binding lookups (`read_active_task_binding`) ignore unimported sibling traffic unless `SourceAuthority` keeps a bind/unbind; and ledger catch-up enforces occurred-time watermarks, transcript fingerprints, deterministic IDs, and bounded `ts_utc` waits.
- **CI, crash windows & release integrity (`Rust 1.100`, `Go 1.27.4`):** Release bundles (`tar.gz`, `.deb`, `.msi`, `.nsis`) are opened and checked for all 5 workspace binaries (`gitpulse`, `gitpulse-mcp`, `gitpulse-hook`, `gitpulse-ptyd`, `gitpulsed`) with tokens stripped from 7-Zip; every workflow pins actions by SHA and forbids skippable release-gate jobs/steps (`check:workflows`); `scripts/crash-windows.json` pins crash-recovery invariants; `ci:local` detects working-tree drift mid-run; and `bun run test:tz` covers DST/timezone boundaries.

## Breaking Changes & Upgrade

- **Task profile migrates one way to `dc-store` store schema 11 and workbench schema 17.** Hosts built against older schemas refuse migrated profiles (`schema_unsupported`); backups are kept beside the profile (e.g., `<profile>.pre-schema-14.bak`). Schema 16 rewrites `inbox` tasks to `backlog` (archived and deleted included), and schema 17 adds cross-repo queues, GitHub issue sync outbox, and DAG readiness. Rebuild GitPulse, Manvi, `dcstore`, and DevCouncil from the same `dc-store` together before opening the profile.
- **DevMap store migrates one way to schema 29 (`zstd`-compressed), and `devmap_*` MCP tools default to depth 3 (down from 10).** Rebuild/reinstall the `devmap` CLI alongside GitPulse.
- **Ledger schema bumps to writer generation 2 (OD 1).** Rebuild and reinstall `gitpulsed` and `gitpulse-mcp` together; gen-1 writers refuse migrated ledgers.
- **Reinstall `gitpulse-mcp` and `gitpulse-hook` (`bun run mcp:install`)** so hooks (`deliver`, `worktree-create`, `worktree-remove`, `peer-inbox`, `stop-or-notify`) and store schemas match, and verify all 5 binaries build cleanly (including `gitpulse-ptyd` on Unix, now unconditional under protocol 3, with hosted Manvi `keep_terminals_running` defaulting on). In released apps, a missing `gitpulse-hook` now blocks guarded agent calls instead of letting them through.
- **Toolchains & Git floors:** Building from source requires **Rust 1.100+** and **Go 1.27.4+** (`gitpulse-rustc` supports Cargo 1.100's `build/<pkg>/<hash>/` layout). Runtime requires **Git 2.36+** (with **2.45.1+** for clones and **2.50.1+** for recursive submodules; force push uses `--force-with-lease --force-if-includes`).
- **Behavioral & security changes:** Dead `cmd_stash_pop` is removed (`cmd_stash_action` replaces it); child processes drop relative `PATH` entries and Manvi uses an allowlisted environment; `gitpulse_complete_task(done)` requires a passed Manvi verification on HEAD (otherwise moves to Review); `gitpulse_add_task` enforces open-work similarity checks (`reviewed_related`) and optional `expected_revision`; `.gitpulse/hooks*` require explicit user approval per edit; hook notifications from unknown terminal sessions are refused; and **Option as Meta** in terminals defaults on for macOS (disable in Settings → Appearance if Option types characters like `@`).

## Known Issues

- **GPU terminal benchmark pending:** WebGL terminal rendering is enabled by default before its TUI-redraw A/B benchmark in `docs/PERFORMANCE.md` has completed; context losses fall back to DOM rendering and Settings → Appearance can disable GPU rendering.
- **Hidden-repository tasks filter is a reader preference:** Store totals and per-column paging still count hidden repositories' tasks, and archive/inbox/badges include them.
- **Platform signing & installer inspection limits:** macOS builds are ad-hoc signed (`signingIdentity: "-"`, not notarized) and Windows builds are unsigned; `.dmg`, `.rpm`, and AppImage bundles have checksums verified in `release.yml` but are not unpacked to inspect internal binaries. Prebuilt remote tool installs remain unavailable (installs build from source).
- **Platform observation & ledger boundaries:** On Windows without a process scan, live Codex/Antigravity/DevCouncil/Manvi sessions report unknown rather than zero (Codex history still ingests via rollouts afterwards); non-Unix ledgers fall back to the roots-only rule; and identical reflog entries outside the 200-entry window or deleted mid-chain can misalign ordinals.
- **Legacy schema-mismatch hazard:** Running an older `gitpulse-mcp` or `gitpulse-hook` against a migrated profile will fail until `bun run mcp:install` is re-run.
