# GitPulse 2.0 (1.99.0 Beta)

GitPulse 2.0 is a major release of the desktop workspace, agentic control plane, and terminal host. It ships in the repository and bundle manifests as `1.99.0` (the 2.0 beta) so plain numeric bundle versions sort cleanly before `2.0.0`. It streamlines the interface into 4 views and 11 sections with floating glass panes, a 17-preset theme gallery and macOS window wallpapers, makes the out-of-process Unix terminal host (`gitpulse-ptyd`) and hosted Manvi (`keep_terminals_running`) the default, adds pre-operation Git snapshots (`refs/gitpulse/ops/<n>`) and per-turn agent checkpoints (`refs/gitpulse/turns/`), upgrades the task profile to workbench schema 17 (merging Inbox into Backlog and adding cross-repo queues, GitHub issue sync outbox, and DAG launch readiness), seeds new agent worktrees with a copy-on-write DevMap store (`~1.2 s` query-ready vs `~7.6 s` cold), and moves the toolchain floor to Rust 1.100 and Go 1.27.4.

## Highlights

- **Streamlined 4-view, 11-section layout and floating panes.**
  - **Work (`Overview · Remote · Tasks`)**: Resolve and Policy are folded into the surfaces they act on. The 3-way conflict editor leads **Overview** whenever a merge, rebase, cherry-pick, or revert is parked; *Branch and tag cleanup* and *Policy activity* live as disclosures on Overview; and *Outgoing commits*, *Issues to Tasks*, and *Push release tag…* live on **Remote**.
  - **Code (`Explorer · Map`)**: Search and Blame are inline toggles inside Explorer, while **Map** opens on an overview of repository size, caps, and critical files with hover tooltips across files, symbols, and subsystems.
  - **History (`Graph · Diff`)**: Reflog (*HEAD moves*) and regression *Suspects* fold into Graph's `Commits | HEAD moves | Suspects` switcher above one shared commit-details pane. **Diff** gains a **History (`⌥H`)** rail tab that draws the solved commit graph beside the diff, with rich commit hover cards (full body, `git notes`, verification status) and `Shift+click` `older..newer` commit-to-commit comparison.
  - **Insights (`Pulse · Coverage · Health · Storage`)**: Secrets folds into **Health** under a single health verdict, and long report lists across Health, Storage, Hygiene, Pulse, Fleet, Coverage, and Map open on their first five rows with a **Show all N** toggle.
  - **Floating cards and roomier Settings**: Sidebars and workspace panes float as rounded cards on the window ground, Settings expands to `1024×736` (`208px` category rail) with grouped `gp-card` sections, repository tab context menus are streamlined with icons, and double-clicking a page header or empty background minimizes an expanded terminal dock.
- **Theme preset gallery, My themes shelf, and macOS window wallpapers.**
  - **17 built-in theme presets (`src/lib/ui/appearance/presets.ts`)**: Standard (*Neural HUD*, *Reactor*, *Pure Black*, *Crimson*, *Phosphor*, *Synthwave*, *Paper*), Developer (*Amber CRT*, *Blueprint*, *Midnight IDE*, *Arctic*, *Solar Dark*, *Daylight*), and Science Fiction (*Nebula*, *Orbital*, *Neon City*, *Hyperspace*), each validated against the contrast guard and palette-derived material floor.
  - **My themes shelf (`savedThemes.ts`)**: Save the active look or retain up to 24 imported `gitpulse-theme/1` files across appearance resets.
  - **Window wallpapers (`backdrops.ts`, `wallpaperStore.ts`, macOS)**: Eleven seeded static SVG backdrops (*Mesh*, *Aurora*, *Topography*, *Prism*, *Dusk*, *CRT scanlines*, *Blueprint*, *Nebula*, *Orbit*, *Skyline*, *Warp*) or a custom raster image re-encoded to a `<= 2560px` JPEG in IndexedDB, painted beneath `--mac-shell-veil` and cleared under Reduce Transparency or increased contrast.
- **Unconditional Unix terminal host (`gitpulse-ptyd`), session recovery, and default-on hosted Manvi.**
  - On Unix (`#[cfg(unix)]`), PTY terminal sessions always live in `gitpulse-ptyd` (`docs/TERMINAL_HOST.md`), surviving app quit or crash. Quitting with active sessions asks whether to leave or stop them.
  - **Settings → Agents → Keep managed agent runs running when GitPulse quits** (`keep_terminals_running`) defaults to on, hosting managed Codex and Claude runs in a detached `manvi serve --listen` process.
  - **Durable terminal session ledger (`terminal-sessions.v1.jsonl`)**: Bounded 64-row JSONL recovery log and `TerminalResume` (`--fork` support) across restarts and unexpected exits.
- **Pre-operation Git snapshots (`refs/gitpulse/ops/<n>`) and agent turn checkpoints (`refs/gitpulse/turns/`).**
  - **Guarded Git operation undo**: Allowed agent Git mutations record pre-operation snapshots under `refs/gitpulse/ops/<n>` via the desktop single-instance mailbox (`src-tauri/src/engine/git_writer.rs`), with CAS-verified restore (`cmd_undo_op_snapshot`) and dirty-worktree confirmation in `ReflogViewer.svelte`.
  - **Turn checkpoints & `gitpulse_turn_checkpoints` MCP tool**: When `turn_checkpoints.enabled` is on, hooks capture working-tree state at turn start and end using a private index that preserves the real index `mtime` and omits `.env*` untracked files (`src-tauri/src/engine/turn_checkpoint.rs`). Agents and tools can inspect checkpoint lists and bounded patches via `gitpulse_turn_checkpoints`.
- **Workbench schema 17, five-column Tasks board, automatic column fill, and live on-screen refresh.**
  - **Inbox merged into Backlog (schema 16 → 17)**: The Tasks board has five columns (*Backlog*, *Ready*, *In progress*, *Review*, *Done*). Saved views, `status:inbox` searches, `tasks/` briefs, and legacy MCP calls automatically map `inbox` to `backlog`. Schema 17 (`dc-store` at `b5215026`) adds cross-repo queues (`workbench/queue_driver.rs`), a two-way GitHub issue sync outbox (`workbench/github_sync.rs`), and DAG launch readiness (`workbench/terminal_launch.rs`).
  - **Automatic column fill & `liveOnScreen` refresh**: After reading the initial 30 cards per column, `fillBoard` (`boardPaging.ts`) automatically pages remaining cards in 200-card chunks up to 2,000 cards while the column cursor matches. Live task surfaces (`liveOnScreen`) stay active whenever the window is on screen (even unfocused) so external agent writes appear within a second.
  - **Two-row Tasks header & inbox notification dismiss/restore**: Organizes the Tasks header into a title row and toolbar row (`PageHeader.svelte`, `TaskBoard.svelte`), adds **Dismiss** and **Restore** to attention inbox rows (`AttentionInbox.svelte`, `attentionDismiss.ts`), adds `expected_revision` CAS protection to `gitpulse_add_task` overwrites, and caches task verification verdicts through `verdict_memo` with an exact SQLite change signal and shared byte budget.
- **Claude Code worktree hooks, instant DevMap seeding, `.worktreeinclude`, and live MCP sessions.**
  - **Claude Code `WorktreeCreate` & `WorktreeRemove` hooks**: `claude --worktree`, `EnterWorktree`, isolated subagents, and workflow sessions receive GitPulse-provisioned worktrees (`add_worktree_with_devmap`) with approved `post_create` hooks, CoW dependency caches, `.worktreeinclude`, and a copy-on-write clone of the main checkout's DevMap store (`seedDevmap`, query-ready in `~1.2 s` instead of `~7.6 s` cold).
  - **`.worktreeinclude`**: Copies untracked, ignored regular files matching `.worktreeinclude` from the anchor checkout via reflink or bounded copy across all worktree creation paths.
  - **Live agent sessions over MCP (`gitpulse_sessions` & `agents.live`)**: `gitpulse_sessions` reports running sessions (`is_caller`, `run_id`, `task_id`, `state`, `state_source`, `state_age_s`) with zero `git` spawns, and `gitpulse_insights` reports `agents.live` across Claude Code, Codex, Antigravity, DevCouncil, and Manvi plus `served_by` shared app-read metadata.
- **Manvi Anthropic account registry, Firebase diagnostics, and commit author GitHub avatars.**
  - **Anthropic account registry (`~/.anthropic-accounts`)**: Launches `manvi serve` via `anthropic-account exec --no-fallback --repo $HOME -- manvi` (`src-tauri/src/harness/anthropic_account.rs`) without reading or storing an Anthropic API key in GitPulse, and displays `Cloud · <model>` on the status-bar pill (`HarnessBadge.svelte`).
  - **Firebase App Hosting diagnostics**: Classifies Firebase CLI failures with actionable next steps and redacted *Copy diagnostics*, isolates `firebase-debug.log` in a temporary directory, and reports timed-out rollouts as an unknown outcome so users do not double-deploy.
  - **GitHub author avatars**: Commit rows in Graph fetch and cache GitHub author avatars (`src-tauri/src/github/avatars.rs`, `AuthorAvatar.svelte`) with initials fallback.

## Fixes & Hardening

- **Task-scope command fence & cross-checkout write guard (`ft-d3bd46c0`)**: `command-gate` fences argument-writing programs (`sed -i`, `tee`, `cp`, `mv`, `rm`, `truncate`, `touch`, `dd of=`, `perl -i`, `install`, `ln`, `rsync`, `patch`) and refuses `scope.other_checkout` when a bound session writes to another checkout of the same repository.
- **Collision path folding (`ft-9cfd5574`)**: Collision detection folds file-vs-directory, case-insensitive filesystem, and submodule paths, and `SessionStart` (`session-brief`) queries the running GitPulse app before scanning worktrees directly.
- **Antigravity (`agy`) hook compatibility**: Removed `PreToolUse` hooks (`collision-guard` and `command-gate`) from `plugins/gitpulse/hooks.json` and `plugins/gitpulse-agy/hooks.json` because Antigravity IDE 2.32.1 denied tool calls whose pre-tool hook returned `{}` without `"decision":"allow"`. Informational hook notices without a permission decision now render as `{"reason": ...}` rather than `{"decision": "ask"}`.
- **Expanded secret redaction (`dc-redact` at `cbd51369`)**: Redacts bare Google OAuth credentials (`ya29.`, `1//`, `GOCSPX-`), 25-char GitLab tokens (`gldt-`/`glft-`/`glrt-`/`glwt-`), Slack `xoxe-` tokens, AWS `ABIA`/`ACCA`/`A3T` key IDs, HuggingFace `api_org_` tokens, and CLI passwords after `command=curl` / `$(curl`, while eliminating false positives on `fn npm_…()`, `MIN_TOKEN_NAP`, `++latest`, and single-brace templates.
- **Health automatic scans & secrets signal crash reporting**: Automatic dependency and secrets scans wait for the pane to settle, skip fresh results, and hold off after a failure (stating why), and a secrets scanner killed by a signal is reported as a crash naming the signal.
- **Bare push upstream planning**: Planning a bare `git push` reads the branch's own upstream configuration (`branch.<name>.remote` and `branch.<name>.merge`) and never falls back to `push -u` when the config read fails.
- **History, Diff, and Code fixes**: Go-to-line in Code Viewer works again; selecting a commit in *HEAD moves* or *Suspects* stays pinned across graph reloads; branch range comparisons (`main...feature`) in Diff no longer list working-tree files; and read-only hook ledger binding lookups (`read_active_task_binding`) only refuse unimported sibling rows that would be kept as a `bind` or `unbind` under `SourceAuthority`.
- **Rust 1.100, Go 1.27.4, and CI release gates**: Crates declare `rust-version = "1.100"` (handling Cargo 1.100's `build/<pkg>/<hash>/{out,run,fingerprint}` layout in `gitpulse-rustc`), Go helpers move to Go 1.27.4, `scripts/crash-windows.json` pins crash-recovery invariants against Rust source, `scripts/check-workflows.mjs` forbids skippable jobs or steps in release-gate workflows, `ci:local` records and verifies the working-tree fingerprint across the run, and `bun run test:tz` tests date handling across `America/New_York`, `Pacific/Auckland`, and `Asia/Kolkata`.

## Upgrade & Breaking Changes

- **Task profile migrates one way to workbench schema 17 (`dc-store` at `b5215026`).** Every task held as `inbox` is rewritten to `backlog` on first open (schema 16), and schema 17 adds cross-repo queue, GitHub issue sync outbox, and DAG launch readiness tables. Rebuild GitPulse, Manvi, and DevCouncil from the same `dc-store` and run `bun run mcp:install` so `gitpulse-mcp` and `gitpulse-hook` match.
- **Unix terminals always run in `gitpulse-ptyd`.** Ensure `gitpulse-ptyd` is built alongside the app (`cargo build` / `bun run tauri dev` builds all five workspace binaries: `gitpulse`, `gitpulse-mcp`, `gitpulse-hook`, `gitpulse-ptyd`, `gitpulsed`).
- **Rust 1.100 and Go 1.27.4 minimum toolchains** when building from source.
