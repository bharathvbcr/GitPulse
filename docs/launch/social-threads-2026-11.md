```text
"If the product is free, you're the product."

GitPulse is free. So I made it something you can check instead of something you have to trust:

• no telemetry in the app
• no account or sign-in
• all of the code is on GitHub under MIT/Apache-2.0

GitPulse is a local-first desktop Git client built for agentic coding. It has a commit graph, diffs, a 3-way conflict editor, the reflog, PRs and Actions. Around that sits a workspace for running several coding agents across your repositories at once.

The agents stay yours. Claude Code, Codex, Antigravity and Grok run as their own CLIs, in your terminal, signed in to your own accounts. GitPulse doesn't sit between you and the model. It launches, watches and guards them:

→ each agent gets its own git worktree
→ a collision radar warns before two agents edit the same file
→ a command gate, plus a secret check on commits
→ undo snapshots before risky operations
→ a load scheduler so the laptop stays responsive

On pricing: individual features stay free. If I ever charge, it will be for team features. There are no paid plans today.

It's an early beta (v0.2), tested on macOS. Windows and Linux builds exist but haven't been tested yet.

If you run more than one coding agent at a time, what breaks first for you?
```
